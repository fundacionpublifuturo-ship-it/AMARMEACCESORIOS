      Carga masiva desde CSV

      Mismo formato del archivo maestro de Drive. El SKU es la llave: si ya existe se actualiza, si no existe se crea con stock = 1.

      Arrastra el archivo .csv aquí o selecciónalo

      Columnas reconocidas: SKU, Categoria, Nombre_Producto (o Nombre), Precio_COP (o Precio), Imagen_URL_Directa / ID_Drive, Etiqueta (SALE), Stock (opcional).

      Resumen antes de confirmar

      Publicar cambios en el sitio

      El sitio público lee el catálogo embebido en index.html. Descarga el bloque actualizado y pégalo reemplazando el contenido de <script id="amarme-data">.

      En modo local el stock también se guarda en este navegador, así que el catálogo público lo refleja de inmediato en este equipo. Para que lo vean todas las clientas, publica el JSON o conecta Supabase.

      Inventario en la nube (Supabase)

      Estado actual:

      Con Supabase el login usa autenticación real (contraseñas con hash en el servidor) y el stock se sincroniza entre todos los dispositivos. Instrucciones y SQL en el README.

      Respaldo y restauración

      Guarda una copia completa (catálogo + ventas) o restaura una anterior.

      Seguridad

      Sesión iniciada como .

      En modo local la clave se valida contra un hash SHA-256 dentro del archivo: sirve para que nadie entre por accidente, pero no es seguridad real — cualquiera con el archivo puede leerlo. Para un panel realmente protegido usa el modo Supabase.
